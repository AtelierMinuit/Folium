Folium

Encuentra. Obtén. Organiza.

La utilidad documental nativa para macOS. Diseñada con precisión para transformar enlaces web en documentos identificados, validados y organizados en tu biblioteca local.

Ver en GitHub Descargar Release
🎯

Flujo de 2 Pasos

Inspección silenciosa antes de descargar. Verifica portada, autor y páginas antes de transferir datos pesados a tu disco.

📂

Biblioteca Dual

Navega visualmente mediante la cuadrícula de Portadas renderizadas o utiliza la Lista detallada con filtros instantáneos.

🔍

Inspector Técnico (⌥⌘I)

Accede a encabezados HTTP, Server, ETag, Content-Length y al log completo de eventos sin sobrecargar la interfaz principal.

🛡️

Deduplicación Criptográfica

Validación estricta de encabezados %PDF- y hash SHA-256 en bloques de 64 KB vía CryptoKit para evitar duplicados.

🔒

100% Local & Privado

Sin rastreadores, sin analítica y sin telemetría. App Sandbox y Hardened Runtime activos según las directrices de Apple.

⚡

macOS Nativo

Construido con Swift 6, SwiftUI, SwiftData y Swift Concurrency. Rendimiento óptimo en Apple Silicon (arm64).

Compilación Rápida

Compila Folium directamente desde la terminal con Xcode:

# 1. Clonar el repositorio
git clone https://github.com/AtelierMinuit/Folium.git
cd Folium

# 2. Compilar binario Release
xcodebuild -scheme Folium -configuration Release build

# 3. Disfrutar de Folium
open build/Folium.app
