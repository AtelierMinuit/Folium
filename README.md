# Folium

**Encuentra. Obtén. Organiza.**

Folium es una aplicación documental macOS que transforma un enlace en un documento identificado, validado, y catalogado en una biblioteca local.

## Estado

* **Auditoría Inicial:** Implemented
* **Bootstrap:** Implemented (Proyecto Xcode `Folium.xcodeproj` generado)
* **Networking & Downloads:** Implemented
* **PDF Validation:** Implemented
* **SwiftData Persistence:** Implemented
* **Folium Library UI:** Implemented
* **Security & Hardening:** Implemented

## Requisitos

* macOS 14.0+
* Apple Silicon (arm64) o Intel
* Xcode 15+ / Swift 6.0

## Compilar y Ejecutar

Puedes abrir `Folium.xcodeproj` y compilar usando Xcode, o construir directamente desde la línea de comandos:

```bash
xcodebuild -scheme Folium build
```
